# Safety notes

The current script is an early prototype, not a certified repair or optimization product.

System Restore may be unavailable, may fail, and does not replace a full file backup. The script's startup-entry backup covers only the classic Run registry entries it disables. It does not provide full rollback for unrelated Windows changes.

Do not run this tool on production or business-critical devices until the exact version has been reviewed and tested. Always inspect source changes before updating or executing the script.
