# Security Policy

Please do not publish exploitable vulnerabilities in public issues.

Report security concerns privately to the project maintainer through the contact method listed on the NH Digital website: https://nhdigital.shop

Include the affected file/version, impact, reproduction steps, and a suggested mitigation if available. Do not include passwords, API keys, or personal data.

This is an early-stage project. Do not assume the software has undergone an independent security audit.
